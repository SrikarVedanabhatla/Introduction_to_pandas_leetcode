# Introduction to Pandas – LeetCode Study Plan

This repository contains solutions to LeetCode-style problems using **Python's Pandas library**. It is designed for beginners and intermediate learners to practice **data manipulation and analysis** in Python.

## Topics Covered
- Creating and manipulating **DataFrames** and **Series**
- Indexing, selecting, and filtering data
- Aggregation, grouping, and pivot tables
- Handling missing data and duplicates
- Merging, joining, and concatenating datasets
- Applying functions and vectorized operations

## Purpose
The aim of this study plan is to help learners strengthen **Python data analysis skills** while solving practical coding problems. Each solution is explained clearly to highlight both the **code** and the **problem-solving approach**.
